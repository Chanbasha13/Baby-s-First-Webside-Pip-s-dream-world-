## ✨ What's Inside?

### 🌌 A Living Celestial World
Explore a layered night sky with glowing stars, drifting clouds, moonlight, constellation lines, atmospheric lighting, and subtle 3D-inspired depth.

### 🐣 Meet Pip
Pip is the little dream engineer at the heart of this world. Explore the environment and discover personality reactions that make the experience feel more alive.

Follow Pip's journey through four little chapters:

- **Lullaby Lab** — experiment with musical chimes.

Play a timed mini-game, catch falling dreams, build combos, and try to beat your best score.

### 🎵 Tiny Sounds & Surprises
Discover chimes, lullaby controls, sparkle effects, hidden interactions, and little details waiting to be explored.

## 🎨 The Design Philosophy

The world follows a simple idea: **make the web feel a little magical without making it difficult to use.**

- Warm cream, berry, peach, and celestial tones
- Friendly character illustrations and storybook details
- Layered CSS and SVG effects for depth
- Small interactive discoveries rather than overwhelming effects
- Responsive layouts for desktop and mobile
- Keyboard-accessible controls and reduced-motion considerations

The experience is designed to reward curiosity. Some discoveries are easy to spot; others invite visitors to slow down and explore.

## 💻 Run It Locally

### Prerequisites

- [Node.js](https://nodejs.org/) — a current supported version
- npm, included with Node.js
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Chanbasha13/Baby-s-First-Webside-Pip-s-dream-world-.git
```

### 2. Enter the project folder

```bash
cd Baby-s-First-Webside-Pip-s-dream-world-
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal, usually `http://localhost:5173`.

### 5. Create a production build

```bash
npm run build
```

Vite generates the production files in the `dist/` directory.

## 🔒 Privacy & Storage

Some preferences, game progress, and guestbook entries use browser-local storage.

- Guestbook entries are local to the browser and are not a shared online guestbook.
- Saved data may not appear on another device or in another browser.
- Clearing browser storage may remove locally saved information.
- The project does not require visitors to create an account to explore the experience.

## 💭 The Story Behind the Project

Pip is a little dream engineer working the midnight shift. Every star is a possibility, every lantern is a small act of kindness, and every dream is something worth delivering.

This project explores a different kind of portfolio: instead of simply listing work, it invites visitors to experience it. The story, mini-game, constellations, music, and hidden quest turn browsing into an adventure.

The goal was to create a place that feels playful and memorable while still demonstrating frontend development, interaction design, responsive styling, and attention to detail.
