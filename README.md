# 🌙 Pip's Dream World

**Good things start small.**

Baby’s First Website % Welcome to Pip's Dream World — a tiny celestial corner of the internet where a little skull baby dreams among the stars, collects memories, and invites visitors to explore a world of wonder.

## ✨ About the Project

Pip's Dream World is a creative, interactive portfolio website built for the haX.baby Baby's First Website Hackathon. It combines a dreamy night-sky atmosphere, playful interactions, and storybook-inspired visuals.

## 🌟 Features

- ☀️ **Day & Midnight Modes** — switch between two moods.
- 🌌 **Celestial Dream Environment** — floating elements, stars, and sparkling effects.
- 📖 **Pip's Origin Story** — explore Pip's journey through story scenes.
- 🪄 **Interactive Project Showcase** — discover Lullaby Lab, Nightlight Collection, and Dream Delivery Routes.
- 🎮 **Catch the Falling Dreams** — play a small interactive dream-catching game.
- ✨ **Constellation Atlas** — explore constellations and unlock discoveries.
- 📖 **Guestbook** — leave a message for Pip.
- 🎵 **Bedtime Music & Chimes** — enjoy gentle synthesized sounds.
- 🌙 **Hidden Easter Eggs** — discover secrets while exploring.

## 🚀 Run Locally

**Requirements:** Node.js and npm.

1. Clone the repository:

   ```bash
   git clone https://github.com/Chanbasha13/Baby-s-First-Webside-Pip-s-dream-world-.git
   ```

2. Open the project folder:

   ```bash
   cd Baby-s-First-Webside-Pip-s-dream-world-
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed in your terminal.

## 📦 Production Build

```bash
npm run build
```

Vite generates the production files in the `dist` directory.
